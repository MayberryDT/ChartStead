# 03 — Guided CFP publishing and submitter follow-up

**What to build:** A guided organizer workflow for configuring and publishing multiple CFP forms, with draft-versus-published safety, basic conditional behavior, uploads, real confirmation email, and secure signed-link editing for submitters.

**Blocked by:** 02 — First proposal end to end.

**Status:** ready-for-agent

- [ ] An organizer can create, name, preview, publish, close, and reopen more than one CFP form for an event.
- [ ] The guided builder covers welcome content, proposal fields, track choices, speaker and repeatable co-speaker information, supporting links, and files.
- [ ] The supported field set has required settings, ordinary validation, and sentence-readable basic conditions.
- [ ] Preview and public production forms use the same runtime and event theme behavior.
- [ ] Editing a draft does not alter the published form until the organizer explicitly republishes it.
- [ ] A speaker can upload and replace an allowed file with clear progress, limits, and failure recovery.
- [ ] Successful submission queues and sends a real branded confirmation email with one clear action.
- [ ] The confirmation email contains a secure signed link through which the submitter can edit the proposal.
- [ ] Invalid, expired, or revoked signed links fail safely without exposing proposal data.
- [ ] Tests cover draft/published separation, conditional behavior, upload failure, confirmation delivery state, and signed-link authorization.
